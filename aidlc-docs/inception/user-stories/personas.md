# User Personas

## Persona 1: 고객 (Customer)

### 프로필
- **이름**: 김고객
- **역할**: 매장 방문 고객
- **사용 기기**: 테이블에 설치된 태블릿 (브라우저 기반)
- **기술 수준**: 초급~중급 (스마트폰 사용 가능한 일반인)

### 목표
- 직원 호출 없이 빠르게 주문하고 싶다
- 메뉴를 천천히 살펴보고 원하는 것을 고르고 싶다
- 주문한 내역과 상태를 확인하고 싶다
- 추가 주문을 쉽게 하고 싶다

### 동기
- 대기 시간 없이 즉시 주문
- 직원에게 말하지 않아도 되는 편리함
- 주문 실수 방지 (직접 확인 후 주문)

### 불편사항
- 복잡한 UI로 인한 주문 지연
- 주문 후 상태를 알 수 없는 불안감
- 페이지 새로고침 시 장바구니 초기화

### 사용 시나리오
1. 테이블에 앉으면 태블릿이 자동 로그인된 상태
2. 메뉴를 카테고리별로 탐색
3. 원하는 메뉴를 장바구니에 담기
4. 장바구니 확인 후 주문 확정
5. 추가 주문 시 반복
6. 주문 내역에서 상태 확인

## Persona 2: 관리자 (Admin)

### 프로필
- **이름**: 박관리
- **역할**: 매장 운영자/매니저
- **사용 기기**: 데스크톱 또는 태블릿
- **기술 수준**: 중급 (POS 시스템 사용 경험)

### 목표
- 들어오는 주문을 실시간으로 확인하고 싶다
- 테이블별 주문 현황을 한눈에 파악하고 싶다
- 메뉴를 쉽게 관리하고 싶다
- 테이블 회전율을 효율적으로 관리하고 싶다

### 동기
- 주문 누락 방지
- 매장 운영 효율성 향상
- 인건비 절감

### 불편사항
- 주문이 늦게 표시되어 고객 불만 발생
- 테이블 세션 관리가 번거로움
- 잘못된 주문 수정이 어려움

### 사용 시나리오
1. 매장 오픈 시 관리자 로그인
2. 대시보드에서 실시간 주문 모니터링
3. 주문 상태 변경 (대기중 → 준비중 → 완료)
4. 필요 시 주문 삭제
5. 고객 퇴장을 확인한 후 테이블 세션 종료
6. 메뉴 변경 시 메뉴 관리 화면에서 수정
